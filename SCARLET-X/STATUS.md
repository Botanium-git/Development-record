# Scarlet X — 現状（2026-10-22）

## 製品の目標【ユーザー確定】
- Scarlet Xは独立したブラウザ版X拡張アプリで、WKWebView / WebKitによるデータ取得と認証を維持する。
- UIは必要に応じてネイティブ化し、**公式Xと同じ端末適応・文字計測・レイアウト決定規則**を独自実装で再現してよい。公式Xの内部クラスをそのまま使うことは必須ではない。
- **iPhone 15のスクリーンショットの見た目だけに固定値で合わせない。** SE/iPad等でも公式Xと同じ規則で表示が変わることが必要。
- 開発はプロフィール優先、最終的にはネイティブ表示全体へ拡張。意図的な共有・編集ボタン等のUI差異は保護する。
- 方針正本：[Scarlet X設計・引き継ぎ](https://github.com/Botanium-git/SCARLET-X/blob/develop/Docs/ScarletXArchitectureAndHandoff.md)

## 開発の基本姿勢
- 原則 `develop` で開発し、実機確認した安定状態を `main` に反映。
- 毎回バージョンを上げ、変更は一テーマずつ。ビルド成功≠実機成功。
- UIの配置を単一機種用の固定値で合わせることは最終解にならない。
- 静的解析の実行対象は**現在の課題に答えるものに限定**する。無関係なクラスの延々とした探索を避ける。
